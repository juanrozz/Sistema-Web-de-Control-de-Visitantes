# Sistema-Web-de-Control-de-Visitantes
Proyecto para la gestión automatizada, registro e historial de permanencia de visitantes institucionales.

## Arquitectura y Tecnologías Proyectadas
- **Backend Core:** Django (Python)
- **Servicios Complementarios:** Node.js + Módulo de Inteligencia Artificial (IA)
- **Base de Datos:** Motor Relacional (SQL)
- **Infraestructura:** Contenedores Docker sobre entorno Linux
